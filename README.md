# Puma Industrial Task Management (Full-Stack)

Puma est une plateforme professionnelle de gestion de tâches et de supervision géographique conçue pour le secteur industriel.

Cette version inclut une architecture Full-Stack complète avec :
- **Frontend** : React 19, Vite, Zustand.
- **Backend** : Node.js, Express.
- **Database** : SQLite (Persistence réelle).

## Lancement Local

**Prérequis :** Node.js installé.

1.  **Installation :**
    `npm install`
2.  **Initialisation des données :**
    `node server/seed.js`
3.  **Lancement :**
    `npm run dev`

L'interface sera accessible sur `http://localhost:3000` et l'API sur `http://localhost:3001`.
